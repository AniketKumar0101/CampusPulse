PROBLEM STATEMENT
Challenges in Modern University Campus Environments
01
Campus Disorientation
  • Extensive multi-acre campuses with dozens of academic blocks and multi-story complexes.
  • New students, guests, and delivery personnel frequently struggle to find indoor labs and venues.
  • Standard outdoor GPS fails indoors and cannot show multi-floor CAD layouts.
02
Static, Unaware Routing
  • Traditional maps are static and blind to ongoing construction or safety hazards.
  • Walkers route directly into closed corridors, water leaks, or active repair zones.
  • No accessibility routing for wheelchair users needing elevator paths.
03
Fragmented Dispatch
  • Incident reporting relies on slow phone calls without precise floor/room coordinates.
  • Medical distress calls suffer from delayed response times.
  • Administrators lack real-time public advisory broadcasting across student devices.
THE SOLUTION
CampusPulse: Unified Navigation & Command Platform
Interactive Vector GIS Cartography
Zero-dependency native SVG cartography rendering Sri Sairam Engineering College pathways, buildings, sports arenas, and road networks with fast multi-touch zoom and panning.
Indoor CAD Multi-Floor Wayfinding
Architectural CAD blueprints across campus complexes (Alpha, Beta, Delta Blocks). Users switch between Ground, First, and Second floors with room-level targeting and capacity details.
Hazard-Aware Dynamic Pathfinding
Intelligent graph routing algorithm that automatically recalculates walking paths to bypass reported maintenance zones, water leaks, or safety hazards in real-time.
Security Operations Center (SOC)
Centralized command dashboard for campus security with live telemetry, field triage ticket queue, crew assignments, and instant WebSocket broadcast banners to all student devices.

TECHNICAL ARCHITECTURE
System Architecture & Technology Stack
FRONTEND CLIENT APPLICATION
  • Core: Native HTML5, ES6+ JavaScript, Vanilla CSS.
  • Vector GIS Engine: Native Scalable Vector Graphics (SVG) with pan/zoom and coordinate matrix transforms.
  • UI Theme: Obsidian Aerospace dark design system with Glassmorphic HUD elements.
  • Audio Synthesizer: Web Audio API procedural sound cues without heavy audio files.
BACKEND SERVICES & TELEMETRY
  • App Server: Node.js with Express.js modular REST routing.
  • Real-Time Engine: WebSockets (`ws`) delivering sub-second event propagation.
  • Pathfinding: A* / Dijkstra-based graph search with dynamic obstacle avoidance.
  • Storage & Uploads: Multer multipart processing with JSON spatial datastores.
